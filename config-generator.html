1 — Turn captions on (required)

        
    
          
  1. Edit the page → click the gallery section → Edit Section → Design.
    2. 
          
  2. Set Captions to show. Any caption style works.
    3. 
          
  3. Repeat for every gallery you want to filter.
    4. 
        

        
A gallery section is not a collection, so Squarespace publishes no JSON for it — ?format=json returns rendered HTML with no image data. The caption in the page is the only source, and Squarespace leaves it out entirely when captions are off. The plugin hides them again, so this changes nothing for visitors.

      

      

        
2 — Write the metadata into each caption

        
Click an image → Edit → put your filter data in the caption field.

        
Tags: Interiors > Residential, Branding. Year: 2025. Location: Madrid. Author: Sam.

        

          
RuleDetail

          
Key: value.Each pair ends with . ; | or a new line. The last pair may end with nothing — a missing final full stop is handled.

          
Several valuesComma separated: Tags: Branding, Design.

          
Sub-categoriesParent > Child registers both. Selecting Interiors matches everything under it; Residential narrows to that child.

          
LocationNever comma-split, so Location: London, UK stays one place.

          
Your own keysAny key works. Author: Sam. becomes an Author filter with no configuration.

          
Missing keysFine — an image with no Year simply never matches a Year filter.

          
Plain proseAnything that isn't a Key: value pair stays as the visible caption in Clean mode.

        

      

      

        
3 — Where the code goes

        
    
          
  1. Copy the code with the button in the header.
    2. 
          
  2. In Squarespace, open the page → Page Settings → Advanced → Page Header Code Injection, and paste it there. That loads the filter only on this page and stops the raw caption text flashing before the plugin hides it.
    3. 
          
  3. Or, for every page, use Settings → Advanced → Code Injection → Footer instead.
    4. 
          
  4. Save and open the page.
    5. 
        

      

      

        
Good to know

        
    
          
  1. Filter groups are discovered, not listed. Add a new key to a caption and it becomes a filter on its own.
    2. 
          
  2. Grid, Masonry and Strips are supported. Slideshow, Reel and Stacked are carousels and are skipped with a console notice.
    3. 
          
  3. Masonry and strips are re-laid-out by the plugin. Squarespace positions them once and never recomputes — so filtering them natively would leave holes. A side effect is that they now reflow on window resize, which they don't do natively.
    4. 
          
  4. Images are never re-created — they're shown and hidden in place, so the Gallery Lightbox and other plugins keep working.
    5. 
          
  5. Choices within a group widen results; choices across groups narrow them.
    6. 
          
  6. Filter state uses an f_ prefix so links are shareable and never collide with Squarespace's own ?tag=, which it consumes server-side.
    7. 
          
  7. Each gallery on a page filters independently and gets its own URL scope (f_s1_, f_s2_).
    8.
